# v2.1.0 · 2026-10-31

**面板成了正形，心跳能跑在 Linux 上了，`settings` 不再是启动硬依赖。** 连同一条会把宿主整个带崩的修复，和几处节律上的体验修整。

## 新增：原生面板

原来挤在设置页里的一串折叠区，改成插件管理页里的一个正式面板，注册到 `plugins.bundle.config`：

- 七个 tab：**状态 / 会话 / 素材 / 兴趣 / 画像 / 周报 / 设置**，各管一件事；
- 顶部渐变标题栏（插件 icon + 标题 + 版本徽章）、胶囊式 tab 栏、内容卡片化；
- 状态页是六格指标：上次心跳 / 插件版本 / 今日表达（带进度条）/ 时间注入 / 上次结果 / 此刻动态；
- 设置按「节律 / 时间与状态栏 / 表达 / 专注模式」分组，每个参数都标了生效时机；迁移导入加了二次确认；周报正文默认收起；
- 样式走 `hb-` 前缀的一套 CSS（`ensurePanelStyle()` 幂等注入），颜色全取 `--dsw-alias-*` 变量，深浅主题都跟手。

`settings.section` 上的旧面板在 v2.1.0 一并退役：不再挂第二份 UI，注册失败时只留一条「需要 DSH 0.2.1 及以上」的告警。

**槽位 key 用的是 bundle 短名**（`dsh-heartbeat`，不是 `@kanadego/dsh-heartbeat`）。宿主插件详情页用 `ledger.bundles.has(openPkg.name)` 判断要不要渲染配置区，而 `openPkg.name` 是去掉 scope 的短名——首版写成 npm 全名，结果详情页整块配置区不渲染，面板「装了但看不见」。`scripts/panel-smoke.mjs` 现在直接对短名做断言。

## 修复：`settings` 改软依赖（桌面端装完起不来）

由桌面端 0.2.1-rc.3 上报：装完插件面板显示 `pending`，宿主起不来。

原因是 `settings` 写在模块级 `inject` 里，而 cordis 把模块级 inject 当**硬依赖**——宿主不提供这个服务，插件就永远停在 `pending (waiting for service: settings)`。桌面上光这么一个 pending 就够把整个壳带崩：`openInitialWindow` 报 `Web RPC failed`，随后弹出的崩溃窗口三个按钮全无响应。

设置表单本来只是便利：节律值来自 `data/settings/ui.json` 加 apply 时的 `config`，没有它照样跳。现在改由 `ctx.inject(['settings'], …)` 延迟挂载——心跳靠 `agents` 一个服务就能起，表单在服务出现时挂上、服务消失时它的副作用跟着回收。

顺手清掉两条早已走不到的旧分支（0.1.5 的 `installSection` 与 0.1.1/0.1.2 的 free-function 回退），`@deepseek-ai/dsh-settings` 随之从 dependencies / devDependencies 移除；新增 `tests/plugin-inject.test.ts` 盯住这一行，防止有人把它加回去。peerDependencies 显式列出 `0.2.1-rc.3` / `rc.4` / `rc.5`。

## 新增：最小 Linux / macOS 支持

此前非 Windows 上 `npm install` 会直接被 `EBADPLATFORM` 拒掉，就算装上也活不过第一跳——主密钥要 spawn `powershell.exe` 来解 DPAPI。

现在：

- **主密钥不再硬依赖 PowerShell**：非 Windows 平台把 32 字节密钥直接写成 `data/vault.key`（`0600`，scratch → rename 原子发布，发布前回读比对），AES-256-GCM 加解密仍在本进程完成；
- **三处原本会炸的地方改成讲清楚**：非 Windows 读 KHBV1 容器不再 spawn 一个不存在的 PowerShell，而是明确报「KHBV1 只属于 Windows、数据不跨平台」；KHBV1 主密钥同理——**拒绝而不是静默换新密钥**（换掉等于把已有数据全变成打不开的）；
- **探针干净降级**：`src/core/ps.ts` 在非 Windows 上直接返回失败，截屏 / 空闲检测 / 锁屏检测 / 前台窗口 / 桌面通知因此不再每跳白等一次进程启动。代价是忙闲判定缺席——静默时段、每日上限、冷却照常，但「他大概在忙」这类窗口判断不触发；
- `package.json` 的 `os` 从 `["win32"]` 放开为 `["win32","linux","darwin"]`。

数据**不跨平台搬家**：vault.key 在 Windows 上由 DPAPI 保护，在 Linux / macOS 上是一份权限 0600 的密钥文件，两边互不相认。换平台就是重新开一份数据目录。

## 新增：专注模式

需要安静的时候一键暂停心跳，1–1440 分钟任选，到点自己恢复。不写配置文件、不重启、不影响别的设置；暂停期间一次都不跳，状态栏显示「专注模式 · 至 HH:MM」，设置卡和 CLI 认的是同一份状态（暂停落 `data/focus.json`，重启照样有效）。

## 改进：节律不再踩整点

每跳间隔在基准值上浮动 ±20%（`policy.heartbeat.intervalJitterPct`，0–50，设 0 关掉）。启动那一跳仍固定 15 秒后发起、不参与抖动。

## 修复：子代理会话不再被注入时间

时间注入原先对所有 agent 生效，分身会话里也会冒出「当前本地时间…距上一条消息已过去…」。现在按会话头判定（`origin: subagent` / `delegationDepth > 0`，老版本回退扫 `subagent/descriptor` 事件），子代理一律跳过。

## 改进：闲逛去重与增量

- 入库前查重：完全相同网址、归一化后同名、与近 30 天归档相似度 > 0.85 的条目直接丢弃（短标题不参与相似度判定，避免「话题素材 1 / 11」这类被误杀）；
- 每焦点带回的种子上限从 2 条提到 4 条，一次闲逛的收获不再被同 topic 合并规则吃掉。

## 新增：插件图标

`package.json` 加了 `icon` 字段指向包内 `icon.svg`（一道波形，36×36 视口、圆头线描），插件管理页的卡片与列表都会带上它。同时补了 `locale/en.json` + `locale/zh.json`：插件标题英文环境显示 `Heartbeat`、中文环境显示 `心跳`。
