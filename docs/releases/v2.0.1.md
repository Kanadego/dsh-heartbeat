# v2.0.1 · 2026-10-25

**界面说起英语了**。设置卡、状态卡与报告面板里的文案全部改走 Harness 的 locale 服务——Harness 切成英文，心跳的界面跟着变成英文；而中文界面，一个字都没有动。

## 新增：客户端界面双语

以前心跳的界面文案硬编码在 `client.js` 里，Harness 切到英文时，插件这部分仍然是满屏中文。现在：

- 157 条文案收进 `heartbeat` 命名空间，中文 / 英文各一套；
- 语言切换即时生效，不用重启、也不用刷新页面；
- 设置行、状态卡、素材池、用户画像、周报、迁移——界面上能看到的都在里面。

字符串之外，有几个拼接碎片顺手改成了模板：像「共 3 / 6 字符（在预算内）」这种句子，以前是由七八段字符串拼出来的，现在是一整句模板加几个占位符。

## 保持不变：中文逐字未改

这一版**只搬字符串**，渲染结果与 v2.0.0 完全一致：

- 中文文案一个字都没有改；
- 设置行的标签仍然是函数，所以切语言能触发重渲染（写成预求值的字符串就会丢掉这个能力）；
- 素材池、报告面板里的状态符号（`☑` / `☐`）拆成了符号加文案，两种语言下都还是原来的样子。

## 不受影响：数据与宿主侧

- 数据目录、配置项、RPC 接口都没有动，升级不需要任何迁移；
- **心跳报告正文（引擎室那份）仍然是原来的中文口径**——宿主侧定时生成时没有请求上下文可读，「界面语言该不该影响报告语言」是另一个问题，另行处理；
- 插件声明支持的最低宿主版本不变：`locale` 服务从 DSH 0.1.1 起就有（已逐个版本验过），万一取不到就退回内置中文，不会影响界面启动。
