# v1.9.3 · 2026-10-17

**让心跳学会闭嘴，也让它记得更久**。这一版给素材包加上「留白」——决定不说的时候，正文就是空的，不再为了凑一句话去挑一条不相干的素材；同时把摘要预算拆成分区、给周报加上保留期数，并把设置卡片整个重做了一遍。

## 新增：素材包可以留白

以前每一轮心跳都必须挑一条素材开口，挑不出来也得硬挑，结果就是偶尔冒出一句和当下毫不相干的话。

现在素材包的语义变了：模型的判断从「挑哪条」变成「**要不要开口**」。决定沉默时，正文直接留空，只在账上记一笔「这轮没开口」以及原因——不花冤枉的输出 token，也不制造噪声。

> 留白是否生效取决于模型的指令遵循能力。如果想更稳，建议在系统提示词或长期记忆里补一条对应规则；模型照做了效果就很好，不照做时仍会退回旧行为。

## 新增：摘要预算分区

摘要（digest）的字符预算从 3200 提到 6000，并拆成三个分区各有上限：`tact`（分寸）/ `topic`（话题）/ `wander`（闲逛）。超预算的条目**整条跳过**，不再从句中截断——截一半的句子比没有更糟。

## 新增：周报保留期数

`policy.weekly.keepReports` 默认保留最近 **3** 期周报，超出的自动清理并留痕（`weekly_pruned`）。以前周报会一直堆在数据目录里。

## 修复：节省 token 模式下叫不醒

启用节省 token 模式后，心跳靠定时探测等待用户回来。原来的探测间隔太长且没有恢复钩子，用户回来了心跳还挂着。现在：

- 每 3 分钟探一次；
- 绑定的会话一有新消息立刻恢复心跳；
- 状态栏在此期间显示「你不在，心跳挂起」。

## 调整：出厂默认值

新装的默认节奏变了，升级后**不会**自动改你已经保存的设置：

- 心跳间隔 60 分钟；
- 每日表达上限 10 次；
- 状态栏默认关闭。

想保持旧行为，去设置卡里手动调回去即可。

## 界面：设置卡片重做

- **用户画像**拆成四个分区（兴趣 / 进行中 / 沟通偏好 / 心理），另加一个只读的「引擎室输入」视图，用来核对哪几条画像真的进了引擎室；
- **素材池**改成四个按钮：话题素材 / 聊天素材 / 话题·归档 / 聊天·归档。归档不再单独占一块，点进归档条目按钮会变成「恢复」；
- 引擎室输入视图和各列表都加了滚动区，条目多了不再把卡片撑长。
