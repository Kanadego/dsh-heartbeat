# v2.3.0 · 2026-11-18

**会话闸门、报账锁、账本归档与原生看图：心跳不再对着空会话说话，报账也不会串号。**

## 新功能

- **会话闸门**：投递前核对目标会话——已归档、是子代理、或日志连续三拍读不出来（含真的尝试拉起过也拉不起来的），自动从 `bindings.json` 里摘掉并记审计，不再对着门后没人的会话空转。归档与子代理首次即摘；读不出来与拉不起来要连续 3 拍，期间只要成功读到一次就清零。
- **报账锁**：每次投递包都带唯一 `delivery_id`，`seed_report` 必须原样回填。重复报账、拿旧编号报账直接拒收并留 `report_rejected` 审计；拒收文案不回显当前投递编号（编号只进审计）。
- **账本 / 错题本归档**：`ledger done` 与 `corrections done` 把行移进 `data/ledger-done.md` / `data/corrections-done.md`。崩溃重放、10 分钟内重试、时区造成的同章重跑都不会重复归档，也不会复活已删行；首启自动把旧活页里的 done 行迁进归档（审计 `ledger_done_migrated`）。`corrections`（错题本）成为全局工具，CLI 新增 `ledger open --done` 与 `corrections` 三个子命令，面板并排放「账本 / 归档」两个只读入口。
- **心事匣与状态栏收口**：`notepad` 只在允许投递的会话可见（声明层 `when` 隐藏 + 执行层兜底拒绝），状态栏也只在这些会话渲染；子代理会话不注入时间。
- **截屏识别改用宿主原生看图**：新增 `visionEngine`（`auto` / `native` / `modlens`，默认 `auto` = 模型本身优先，探测不到图片输入能力才回退 ModLens CLI）。被中止的跳按「取消」记账（`beat_aborted`）而不是识图失败；回退原因（`nativeError`）保留在审计里，已脱敏、绝不写截图路径；非法的引擎取值被忽略并按 `auto` 处理，按来源去重审计 `vision_engine_invalid`。
- **面板更耐用**：RPC 通道晚注册的宿主不再一进来就报「RPC 不可用」——挂载时自动重探、只升不降；只读态的开关与输入框显示「—」，不再把兜底默认值当配置值摆给用户看，只读控件不可点击。

## 行为变化（务必注意）

- **沉默按事实记账**：回合正常收尾但正文为空（或只有「本轮沉默」这类声明行）时按沉默记账、不花额度，不再因为「没有报账」被误记成发声失败。报了账但正文空着，以事实为准并保留报账口径供对账。失败型结束（blocked / error / aborted / interrupted / max-tokens / forked）一律不算沉默。
- **实验性静默收尾**：开启后，模型回合正常收尾但没吐正文时记 `turn_concluded` 而不是故障线。四重门控：开关开着、表达轮、结束方式为 `completed`、本轮真的发起过收尾——缺一条仍记 `turn_extraction_empty`。
- **截屏识别默认多一轮模型调用**：`auto` 下每跳会先走模型原生看图，截图进附件库与会话历史；只想用 ModLens CLI 的，把 `visionEngine` 改成 `modlens`。
- **投递包必须回填 `delivery_id`**：不填或填错都会被拒收，这一投不入账（审计可查）。

## 修复

- 中止（看门狗 / 宿主关闭）不再被记成识图失败或决策/表达/周报阶段的普通错误，统一归口为 `beat_aborted`。
- 报账原因（`reason`）不再在重排条目时丢失。
- 归档写盘用原子写（`wx` 旗标 + 失败清理半截目标），并发完成不会互相覆盖。

## 注意

- 升级后建议在面板「设置」确认 `visionEngine`；老配置里没有这一项时按 `auto` 处理。
- 归档文件本身无界增长（`ledger-done.md` / `corrections-done.md`），可以手动删除或轮转，本版不做自动分片。
