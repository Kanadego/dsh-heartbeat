# v2.3.0 · 2026-11-18

**心跳不再对着空会话说话，报账不会串到下一投，账本多了归档页，截屏识别改用宿主自己的眼睛。**

## 新增功能

- 会话闸门：投递前先核对目标会话。已归档、是子代理、或连续三拍都读不出来的，自动摘掉这条绑定并记下原因，不再对着门后没人的会话空转。归档与子代理当拍就摘，读不出来要连输三拍，中途成功读到一次就清零。
- 报账锁：每个投递包带一个本次专属的编号，报账时原样回填。重复报账或拿旧编号来报会被拒收，报账不会串到下一投。
- 账本与错题本归档：完成的事项从活页移进归档页，崩溃重放、短时间重试、时区造成的重复都不会把同一件事记两遍，也不会复活已删的行。第一次启动会自动把旧的已完成项迁进归档。错题本成为全局工具，命令行加了查看归档的入口，面板里并排显示「账本」和「归档」。
- 截屏识别：优先让宿主模型自己看截图，本地识图命令行降为回退。设置里可以选「跟随宿主」「宿主原生」「本地识图」三种。被取消的跳按取消记账，不再报成识图失败。
- 面板更耐用：接口晚注册的宿主，不再一进面板就报「不可用」，挂载时会自动重试；只读状态的开关和输入框显示「—」，不再把默认值当成你的配置摆出来，也点不动。

## 行为变化

- 沉默按事实记账：回合正常结束但正文是空的，按沉默记账、不占发送额度；报过账但正文空着也以事实为准。被拦、出错、中止、超时这类失败结束不算沉默。
- 静默收尾（实验性）：打开后，模型正常结束却没吐正文时记成正常收尾，不再算故障；条件不满足时仍按原来的故障线记。
- 截屏识别默认多一次模型调用：默认「跟随宿主」时每跳会先让模型自己看截图，截图会进附件库和会话历史；只想用本地识图的改成「本地识图」。

## 修复

- 看门狗或宿主关闭造成的中止，不再被记成识图失败或某个阶段的普通错误，统一记成本轮取消。
- 报账时填的原因不再丢失。
- 归档写入改成原子操作，同时完成的多件事不会互相覆盖。

## 注意

- 升级后建议到设置里看一眼识图引擎；老配置里没有这一项时按「跟随宿主」处理。
- 归档页不会自动分片，会一直增长，可以手动清理。
