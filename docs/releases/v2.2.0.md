# v2.2.0 · 2026-11-09

**B 站观看历史成为新的素材来源，扫码登录与静默时段都搬进了面板。**

## 新增功能

- B 站观看历史素材源：每 2 小时拉取一次，过滤短视频、直播间与刚点开就划走的记录。
- `heartbeat bili login`：扫码登录，凭证加密保存在本地。
- 素材 tab 新增 B 站账号卡片，可直接扫码登录并查看登录状态。
- 设置 tab 新增静默时段的起止时间输入框。

## 改进

- B 站素材单独限制 6 条，在候选包里最多占 2 条。
- B 站素材文案改为第三人称，标题保留上限放宽到 100 字符。
- 素材池新增来源维度的配额，超出时按最旧优先收敛。
- 静默时段保存后立即生效，无需重启。
- 投递目标自动跳过已归档会话，全部目标归档时如实记账。
- 静默原因区分为被拦截、无输出、非中文三种。
- 时间注入按消息来源判定，不再进入引擎室轮次。
- 引擎室挂载预设后等待工具就绪，适配 DSH 0.2.2。
- 反刍输出精简为 `{seed_ids, doing}`，去掉无人读取的字段。
- 面板剩余中文文案全部英文化。

## 修复

- 修复 Linux 上打开账本或摘抄本导致宿主整体崩溃的问题（#9，感谢 @dmscode）。
- 修复 Linux 上所有 CLI 子命令静默退出的问题。
- 修复 B 站扫码轮询把「未扫码」误判为登录成功的问题。

## 注意

- B 站素材源默认关闭，需在设置中开启并完成一次扫码登录。
