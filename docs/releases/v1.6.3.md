# v1.6.3

**新增：闲着模式（默认关闭）**

当素材池为空时，心跳默认会沉默一跳（"空池即沉默"）。开启「闲着模式」后，素材池为空时心跳会改用本跳画像 digest 的话题切面兜底，仍走原有投递链路主动搭话——每日表达上限、静默时段、忙碌不打扰等闸门照常生效，只是不再因为"没素材"而什么都不说。

- 新增配置项 `heartbeat.idleMode`（默认 `false`）。
- 设置卡「节律配置」新增「闲着模式」开关，保存即时生效，无需重启。
- 投递链路抽取为共用 `deliverPackage`，素材池与画像兜底两条路径一致地做表达、归账与留痕；画像兜底的话题行不会进入素材池归账（不消耗真实素材）。
