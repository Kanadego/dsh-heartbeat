# v1.7.0

**适配 DSH 0.1.7 接口换代，新增 psy 分区开关与节省 token 模式**

适配 DSH 0.1.7 的接口换代，并新增两个开关。**已在 `0.1.7-rc.2` 上实机验收。**

## 适配（DSH 0.1.7）

- **设置接口**：0.1.7 换掉了插件配置界面的机制（改由宿主根据插件声明的字段自动生成表单），旧写法会失效。心跳现在会自动探测宿主是哪一代，从三代接口里挑能用的——无论跑在哪一版 DSH 上，都不用改配置。
- **客户端服务**：0.1.7 删除了一个客户端旧服务，插件若仍声明它，整个 Web 界面会加载失败（症状：只看到 `Failed to load plugins`，聊天区都进不去）。已移除该声明。
- **节律配置**：不再借宿主的设置接口读写，卡片里的编辑器直接写插件自己的配置文件，点保存立即生效（改间隔会当场重排下一跳），不用重启 DSH。
- **会话消息源**：0.1.7 的会话日志升级到 V4，不再接受旧版通用的消息来源标记——旧写法会让心跳轮次整轮写入失败。已改用自有的来源标记。

## 新增

- **psy 分区开关**（默认关）：开启后画像合并才收 psy 分区条目，关闭时相关条目一律拒收。值写在用户 policy 层，即时生效。
- **节省 token 模式**（默认关）：你离开（键盘/鼠标闲置 ≥30 分钟）或 Windows 锁屏时整跳暂停——不采集、不闲逛、不反刍、不投递，一个 token 都不花；回来自动恢复。探测失败一律放行，绝不因探测故障误暂停。

## 升级提示

- 升级后需**重启 DSH**。
- 宿主从 `0.1.5` 升到 `0.1.7` 会触发会话格式 v4 迁移（**单向、不可降级**，原文件保留），升级前建议备份 `~/.dsh/sessions`。
- 老用户首次打开设置卡时，节律配置以出厂默认呈现属正常；第一次保存会在 `data/settings/ui.json` 生成用户层。

安装/升级方式不变（npm 或 GitHub release）。
