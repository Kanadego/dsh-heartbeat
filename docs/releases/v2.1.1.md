# v2.1.1 · 2026-11-04

修复 issue #8：原生面板在 DSH 0.2.1-rc.3+ 的插件详情页完全不显示。

## 原因

`plugins.bundle.config` 的注册 key 误用短名 `dsh-heartbeat`。v2.1.0 时误判宿主报的是去掉 scope 的短名；实测（宿主 0.2.1-rc.4 源码）plugin-manager 的 `listBundles()` 名字取自 manifest `dependencies` 的 key，即完整包名 `@kanadego/dsh-heartbeat`，详情页以 `ledger.bundles.has(openPkg.name)` 判定是否渲染配置区，key 对不上则 `renderSlot` 不调用，面板整块不显示。

## 改动

- `client.js`：槽位 key 改回 `@kanadego/dsh-heartbeat`，注释写明实测结论与误判来源。
- `scripts/panel-smoke.mjs`：`BUNDLE_NAME` 断言同步改回全名（与 client 一致）。
- `README.md`「版本更新」只保留当前大版本 v2.1.x；v2.0.x 及更早记录移至 `CHANGELOG.md`（已有完整 v2.0.x 编目，本次只把 README 里那块删掉并留指针，避免两边重复）。
- `CHANGELOG.md`：新增 v2.1.1 段，并在 v2.1.0 段标注订正（短名结论作废）。

## 验证

发布前：`node --check client.js` 通过；`node scripts/panel-smoke.mjs` 通过；`node node_modules/typescript/bin/tsc --noEmit` 零错误；`node --import tsx --test "tests/*.test.ts"` 全部通过（以本轮实际输出为准）。

安装/升级方式不变（npm 或 GitHub release）。
