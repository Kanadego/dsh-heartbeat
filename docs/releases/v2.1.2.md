# v2.1.2 · 2026-11-04

**修复 issue #8 跟进：原生面板在 `file:` / 本地安装方式下仍不显示——改为双 key 注册，npm 与本地安装两种方式都恢复。**

## 原因

v2.1.1 只注册了 npm 全名 `@kanadego/dsh-heartbeat`，只覆盖 npm 安装方式。实测（宿主 0.2.1-rc.4 源码）plugin-manager 的 `listBundles()` 名字取自 profile 的 `dependencies` / `dsh.profile.bundles` 的 key——**npm 安装时是全名，`file:` / 本地安装时是短名 `dsh-heartbeat`**，详情页以 `ledger.bundles.has(openPkg.name)` 判定是否渲染配置区。v2.1.1 在本地安装方式下两个名字对不上，`renderSlot` 不调用，面板整块不显示。

## 改动

- `client.js`：`plugins.bundle.config` 改为同时注册 `dsh-heartbeat` 与 `@kanadego/dsh-heartbeat`（同一组件、两个 key），文件头注释与行内注释写明两种安装方式的区别，细节见 CHANGELOG v2.1.2 段。
- `scripts/panel-smoke.mjs`：断言由单值 `BUNDLE_NAME` 改为 `BUNDLE_NAMES` 双 key（短名 / 全名之一），与 client 行为保持一致。
- `README.md`「版本更新」：新增 v2.1.2 段并**醒目提示跳过 v2.1.1**（v2.1.1 的单全名注册只覆盖 npm 安装）；「版本兼容」表的（当前）标记挪到 v2.1.1 – v2.1.2 这一行。
- `CHANGELOG.md`：新增 v2.1.2 段（v2.1.1 段原文不动）。

## 验证

发布前：`node --check client.js` 通过；`node scripts/panel-smoke.mjs` 通过；`node node_modules/typescript/bin/tsc --noEmit` 零错误；`node --import tsx --test "tests/*.test.ts"` 全部通过（以本轮实际输出为准）。
